# めざせ！700m Webアプリ

## iPhoneで使う方法
1. このフォルダ一式を、HTTPS対応の静的ホスティング（例：GitHub Pages）にアップロードします。
2. 公開されたURLをiPhoneのSafariで開きます。
3. 共有ボタン →「ホーム画面に追加」→「追加」を選びます。
4. ホーム画面の「めざせ700m」アイコンから起動できます。

## 注意
- PWAとしてホーム画面に追加するには、HTTPSで公開する必要があります。ZIPを開くだけではホーム画面アプリになりません。
- 記録・チェックはそのiPhoneのブラウザ内（localStorage）に保存されます。ブラウザデータ削除や別端末への移行で消える場合があります。
- 予定の日付・大会日付はユーザー指定の2026年スケジュールに基づく表示です。
